需要 API Key

填写要抓取站点的域名与你的 API Key 即可进入。
域名保存在服务端（后端访问站点接口需要它）；API Key 只保存在你自己的浏览器 cookie 中，不会写入服务端磁盘。

也可以用 ?apikey=你的KEY 直接进入（进入后会自动从地址栏移除）。
Key 只保存在你的浏览器里，填写后即可进入；是否有效会在用到站点接口时才提示。
